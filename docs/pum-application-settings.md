# Application Settings

The Application Settings menu lets you customize your PUM Companion experience. Adjust UI, log area, cloud sync, audio, 3D dice and integration settings.

## Tabs Overview
- **User Interface:** Change theme, font size, and layout options.
- **Log Area:** Configure how logs are displayed and managed.
- **Cloud Sync:** Set up Google Drive integration for backups.
- **AI Settings:** Configure AI providers and API keys (Premium Extra). [Learn more about the AI Assistant](ai-assistant.md).
- **Audio Settings:** Select input devices and adjust audio features.
- **3D Dice:** Enable or customize 3D dice (if available).
- **Integrations:** Connect to Foundry VTT so your rolls land in your log (desktop only). [Learn more about the Foundry VTT integration](foundry-vtt.md).

## Tips
- Settings may change with updates—check back for new options.
- Some features depend on your platform (Windows, Mac, etc).
